## 📚 শেখার পদ্ধতি (Learning Method)

### 🔑 মূল নিয়ম
প্রতিদিন মাত্র **৫টি নতুন শব্দ** শিখবো — কিন্তু সেগুলো ভালোভাবে শিখবো।

### 📅 প্রতিদিনের রুটিন

| সময় | কাজ |
|------|-----|
| সকালে | গতকালের শব্দ復習 করা |
| দুপুরে | নতুন ৫টি শব্দ ১০ বার জোরে পড়া |
| রাতে | শব্দগুলো ১০ বার খাতায় লেখা |

### 🧠 মনে রাখার কৌশল
```
চোখে দেখলে  → ২০% মনে থাকে
মুখে বললে  → ৪০% মনে থাকে
হাতে লিখলে → ৮০% মনে থাকে
তিনটা একসাথে → ১০০% মনে থাকে!
```
