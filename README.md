## 📚 শেখার পদ্ধতি (Learning Method)

### 🔑 মূল নিয়ম
প্রতিদিন মাত্র **৫টি নতুন শব্দ** শিখবো — কিন্তু সেগুলো ভালোভাবে শিখবো।

### 📅 প্রতিদিনের রুটিন

| সময় | কাজ |
|------|-----|
| সকালে | নতুন ৫টি শব্দ দেখা ও পড়া |
| দুপুরে | শব্দগুলো ১০ বার জোরে পড়া |
| রাতে | শব্দগুলো ১০ বার খাতায় লেখা |

### 🧠 মনে রাখার কৌশল
```
চোখে দেখলে  → ২০% মনে থাকে
মুখে বললে  → ৪০% মনে থাকে
হাতে লিখলে → ৮০% মনে থাকে
তিনটা একসাথে → ১০০% মনে থাকে!
```

### ⚠️ গুরুত্বপূর্ণ নিয়ম
```
❌ ভুল পথ → একদিনে ৫০টি শব্দ মুখস্থ করা
✅ সঠিক পথ → প্রতিদিন ৫টি শব্দ ভালোভাবে শেখা
```

## 📝 বানানের মূল নিয়ম (Spelling Rules)

### Vowel এর আওয়াজ
| অক্ষর | আওয়াজ | উদাহরণ |
|-------|--------|--------|
| A | ্যা | CAT = ক্যাট |
| E | এ | BED = বেড |
| I | ই | SIT = সিট |
| O | অ | HOT = হট |
| U | আ | CUP = কাপ |

### অক্ষর জোড়ার আওয়াজ
| জোড়া | আওয়াজ | উদাহরণ |
|-------|--------|--------|
| SH | শ | SHIP = শিপ |
| CH | চ | CHAIR = চেয়ার |
| TH | থ | THANK = থ্যাংক |
| PH | ফ | PHONE = ফোন |
| OO | উ | FOOD = ফুড |

### বড় শব্দ পড়ার নিয়ম
বড় শব্দ দেখলে **ছোট ছোট টুকরায়** ভাগ করুন!

```
BASKET  → BAS + KET  → ব্যাস + কেট → ব্যাসকেট
WINDOW  → WIN + DOW  → উইন + ডো   → উইন্ডো
GARDEN  → GAR + DEN  → গার + ডেন  → গার্ডেন
MARKET  → MAR + KET  → মার + কেট  → মার্কেট
```
